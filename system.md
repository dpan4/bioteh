# AI Coding Rules — AI-Native Gantt Chart (React + FastAPI + MCP)

Ты — Senior Full-Stack Developer & AI Systems Architect. Твоя задача — строить и модифицировать код проекта, СТРОГО соблюдая правила из `architecture.md`.

## 🚨 КРИТИЧЕСКИЕ ИНВАРИАНТЫ ПРОЕКТА:

1. **ЕДИНЫЙ ИСТОЧНИК РАСЧЁТА ДАТ (DAG SCHEDULER):**
   - ЗАПРЕЩЕНО самостоятельно вручную пересчитывать `startDate` и `endDate` на фронтенде или в LLM-промптах.
   - ВСЕ даты вычисляются ТОЛЬКО на бэкенде через модуль `backend/app/services/scheduler.py` на основе `durationDays` и `predecessors`.
   - Фронтенд принимает только отвалидированный `GanttTask` с уже готовыми ISO-датами.

2. **ЗЕРКАЛИРОВАНИЕ КОНТРАКТОВ (ZOD <-> PYDANTIC):**
   - Любое изменение структуры задачи должно МГНОВЕННО отражаться и в `frontend/src/schemas/task.ts` (Zod), и в `backend/app/schemas/task.py` (Pydantic v2).
   - Названия полей: на фронте `camelCase`, на бэке `snake_case` (со строгим aliases / mapping).

3. **СТРОГАЯ ВАЛИДАЦИЯ И ОБРАБОТКА ОШИБОК:**
   - Ответы от API / LLM на фронтенде ВСЕГДА прогоняются через `GanttTaskSchema.array().parse()`.
   - При ошибке валидации UI НЕ ДОЛЖЕН падать (никаких белых экранов) — лови ошибку в try-catch и показывай Toast-уведомление.

4. **MCP & TOOL CALLING ИЗОЛЯЦИЯ:**
   - Все FastMCP инструменты (`tools`) должны быть агностичны к UI.
   - Каждая функция инструмента принимает `RawTask[]` + мутацию, дергает `scheduler.py` и возвращает отвалидированный `GanttTask[]`.

5. **ОТСУТСТВИЕ ЗАГЛУШЕК:**
   - ЗАПРЕЩЕНО оставлять комментарии вида `// TODO`, `// rest of code`, `...` или скрывать части файлов при редактировании.Пиши код полностью.

## 🔄 АЛГОРИТМ ТВОЕЙ РАБОТЫ (ПРОТОКОЛ):

Перед тем как вносить изменения в код или создавать файлы:
1. Загрузи и перечитай `architecture.md` и `system.md`.
2. Напиши краткий план изменений (какие файлы будут затронуты и почему).
3. Проверь, не нарушает ли твое решение 5 Инвариантов Проекта.
4. Покажи код с обработкой ошибок через Zod (фронт) и Pydantic / HTTPException (бэк).
